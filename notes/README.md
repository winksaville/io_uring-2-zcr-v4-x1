# Notes

This directory contains notes and documentation related to the project, each file organized by
topic for easy reference.

The task list is `../TODO.md`, and its `## In Progress` block is the running cycle's record
([Cycle-record](../AGENTS.md#cycle-record)). The conventions for these files are in
[Notes file conventions](../agent-data/notes.md).

- [todo-backlog.md](todo-backlog.md): the long-tail backlog.
- [bugs.md](bugs.md): known defects not yet scheduled.
